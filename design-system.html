Design System · v1

Calm, competent,
and out of the way.

A warm-neutral foundation and a single deep teal-blue, built for two audiences: the support team that makes the guides, and the customers who read them. The brand carries the authoring app — and disappears on the reader site.

01 — Color

Deep teal-blue, one hero

Monochrome-blue by choice. The scale does all the work; no second brand accent competes with it.

600 / #0E5C6B is the hero — buttons, links, active states. 700 for hover, 50 for tints and focus rings.

Warm neutrals — taupe-tinted, never blue-gray

The warmth lives here. Ink is a warm near-black (#211F1B), never pure #000 — softer, more human, easier to read for long stretches.

Functional — muted, state-only

Success#2F7D57 · saved, verified
Warning#B4791F · limit, attention
Danger#B23B3B · destructive

Deliberately desaturated so they read as system feedback, not decoration — and never rival the brand for attention.

02 — Type

Hanken Grotesk, one family

A neo-grotesk with softened terminals — disciplined like Stripe, warm enough to feel human. Weight, not typeface-switching, carries the hierarchy.

Body 400 / UI-emphasis 500 / headings 600. Bold (700) is rare, reserved for genuine emphasis. Uppercase labels get +0.08em tracking — the only place letterspacing appears.

Shadows tint with the ink (rgba 33,31,27), not black — they sit consistently on the warm paper.

04 — Signature

The timeline seam

Pulled from your frame-picker — the one interaction the whole product turns on. Tick marks and a single active dot. It's the section divider, the generating meter, and the step spine, in one motif.

As a progress meter (the ~90s wait):

Filled ticks = stages done · dot = working now · faint ticks = pending. Same shape, three jobs — that repetition is what makes it a signature instead of a decoration.

05 — Two registers

The brand shows, then disappears

Same type discipline runs through both. Only the authoring app carries the teal and the warmth; the reader site takes the customer's color and goes quiet.

06 — Build-ready

Drop-in tokens

Paste into your root stylesheet. Everything above derives from these — change the hero once, the whole system follows.

/* Helpkit design tokens */
:root {
  /* brand — deep teal-blue */
  --brand: #0E5C6B;  --brand-hover: #0B4A57;
  --brand-tint: #EAF3F4; --brand-ink: #072B33;
  /* warm neutrals */
  --paper: #FAF8F4; --surface: #FFFFFF; --subtle: #F2EFEA;
  --border: #E6E1D9; --muted: #8A8377; --ink: #211F1B;
  /* state */
  --success: #2F7D57; --warning: #B4791F; --danger: #B23B3B;
  /* floating toolbar chrome — warm ink, never #000 */
  --tool-bg: #26231F; --tool-hover: #3A3630;
  --tool-fg: #F4F1EC; --tool-sep: #413C35;
  /* radius + type */
  --r-sm: 8px; --r-md: 12px; --r-lg: 16px; --r-pill: 999px;
  --font: 'Hanken Grotesk', system-ui, sans-serif;
}
/* reader site: same tokens, --brand overridden per customer */

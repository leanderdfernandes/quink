For row actions and toolbars, where a word would crowd the line.

```jsx
<IconButton icon="undo" label="Undo" />
<IconButton icon="trash" label="Delete" tone="critical" />
<IconButton icon="image" label="Swap screenshot" raised />
```

Row-level icon buttons live inside `.q-row-actions`, which fades them in on hover and pins them visible on touch. Never the primary action on a screen.

Filters over a list — the library's All / Live / Drafts row.

```jsx
<Chip on count={45}>All</Chip>
<Chip count={2}>Live</Chip>
<Chip count={42}>Drafts</Chip>
```

Selected is an **ink** fill, deliberately not brand: brand belongs to the primary action on the screen, and two brand fills in one row is what made v1's library look busy.
